# منصة رصد الدرجات

مرحباً بكم في كادر ثانوية جنات الخلد للبنات.

هذه المنصة الرقمية تهدف إلى تسهيل عملية رصد الدرجات الشهرية والمتابعة اليومية للطلاب، مع إتاحة الوصول السريع إلى المعلومات اللازمة لكل من المعلمات والإدارة.

## الأهداف
- متابعة الدرجات الشهرية بدقة
- متابعة الأداء اليومي للطلاب
- تنظيم بيانات الدرجات بسهولة
- دعم الكادر الإداري والتعليمي في اتخاذ القرار

## الاستخدام
يمكن لكادر المدرسة استخدام المنصة لمراجعة الدرج��ت، متابعة التقدم، وتسجيل الملاحظات بشكل منظم وسهل.
